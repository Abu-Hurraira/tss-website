# Website Structure

Standalone `tss-website` uses five layers:

1. **Pages** — route screens (`src/pages`)
2. **Components** — layout, navigation, sections, forms (`src/components`)
3. **Data** — CMS-ready content (`src/data`)
4. **Services** — API clients (`src/services`)
5. **Server** — contact/admissions API + email (`server/`)

## Navigation

- Home
- About
- Academics
- Admissions
- Gallery & News (dropdown: Gallery, News, Events, Campus Life)
- Apply Now (CTA)
